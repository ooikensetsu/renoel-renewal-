**管理画面の寸法は `src/app/(admin)/admin.css` に集約している。**
公開サイトの `globals.css` は `html { font-size: 62.5% }`（1.6rem = 16px）を前提に書かれており、
Tailwind の rem 由来の寸法がそのままでは 62.5% に縮む。管理画面の根要素 `.admin-root` に
px のトークンを載せて打ち消しているため、管理画面の見た目が全体的におかしいときは
まずこのファイルを見ること。

**エリアの行は3ファイルにまたがっている（D-19 違反）。**地図のSVGが確定版HTMLの中にあり、
クリック処理が main.js にあるため、いまは1箇所に寄せられていない。エリアを変えるときは
必ず3箇所とも直すこと。docs/debt.md に起票済み。

このマップに2ファイル以上書かれている行は D-19 違反の候補として扱う。マップは散らばりを許すための地図ではなく、散らばりを見つけるための道具である。
