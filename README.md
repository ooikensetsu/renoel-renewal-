# RENOEL リニューアル版 トップページ

現行サイト **[usedrenovation.ooi-kensetsu.co.jp](https://usedrenovation.ooi-kensetsu.co.jp/)** のデザインテイストと写真素材はそのままに、
**[okazaki-bot.github.io/chuko-fudousan-design](https://okazaki-bot.github.io/chuko-fudousan-design/)** のページ構成へ再設計した静的プロトタイプです。

---

## 1. ファイル構成

```
renoel-renewal/
├─ index.html            トップページ
├─ search.html           物件を探す（詳細検索ページ）
├─ assets/
│  ├─ css/style.css      全スタイル（CSS変数でデザイントークンを管理）
│  └─ js/main.js         ドロワー／検索／地図連動／シミュレーター等（依存ライブラリなし）
├─ serve.ps1             ローカル確認用の簡易サーバー（本番デプロイ時は不要）
└─ README.md
```

CSS・JSは2ページで共通です。`main.js` はページ内に該当要素がある場合のみ各機能を初期化します。

## 2. ローカルでの確認方法

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File renoel-renewal/serve.ps1
```

起動後 `http://localhost:8765/` を開いてください。

### search.html（物件を探す）

トップページから詳細検索を切り出した専用ページです。

| # | セクション | 内容 |
|---|---|---|
| 1 | ヘッダー／ドロワー | index.html と共通 |
| 2 | `.pageHead` | パンくず＋「物件を探す」|
| 3 | `#search` 検索ボックス | 種別タブ5種／エリア（必須）／価格／間取り／学区（`#school`）／こだわり条件／件数＋検索ボタン |
| 4 | `#result`「検索結果」| 検索結果一覧の表示イメージ |
| 5 | フッターバナー／フッター／SP固定CTA | index.html と共通 |

**URLパラメータで初期条件を渡せます。**

- `search.html?city=軽井沢町` … 該当市町村をONにして件数を表示
- `search.html?type=mansion` … 種別タブを指定して開く
- `search.html#school` … 学区の行までスクロール

トップページのエリアカード・地図・一覧をクリックすると、`?city=` 付きでこのページへ遷移します。

## 5. 動くもの（JavaScript）

すべて `assets/js/main.js`。外部ライブラリ・ビルドツールは使用していません。

- **検索ボックス**（search.html）：種別タブを切り替えると市町村ごとの件数が入れ替わり、該当0件の市町村は選択不可になります。チェックした市町村の合計件数をリアルタイム表示。URLパラメータ `?city=` `?type=` で初期条件を受け取ります。
- **エリア連動**（index.html）：地図と市町村一覧が相互にハイライトし、クリックすると `search.html?city=◯◯` へ遷移します。
  - 同じページ内に検索ボックスがある場合（search.html に地図を置いた場合）は、遷移せずその場で条件に反映する分岐も入れてあります。
- **資金計画シミュレーター**：元利均等・ボーナス払いなしで実計算します（初期値 物件1,380万円＋リノベ1,518万円／金利0.75%・35年 → 月々78,473円）。
- ドロワー（SP）、スクロールフェードイン、ページトップ、Cookieバー。

## 6. エリアマップについて

トップページの `#area` セクションに、実際の行政界に基づくインラインSVGを設置しています。

- 描画範囲は東信地域15市町村ですが、**操作できるのは施工エリアの7市町村のみ**です。

| 区分 | 市町村 | 表示 | 操作 |
|---|---|---|---|
| **施工エリア** | 佐久市／軽井沢町／御代田町／東御市／小諸市／佐久穂町／上田市 | 濃紺の枠線・大きいラベル | クリック・ホバー・キーボード操作すべて可 |
| エリア外 | 立科町／長和町／青木村／小海町／南牧村／南相木村／北相木村／川上村 | 薄いグレー・小さいラベル | **不可**（`.areaMap__region--out` に `pointer-events:none`。`role` / `tabindex` / `aria-label` も付与していないため、マウスでもキーボードでも触れません） |

- 佐久平駅前の「リノベーションスタジオ RENOEL」をピンで表示（座標 138.4776, 36.2905）。
- 御代田町は区域が細長くラベルが収まらないため、**引き出し線（`.areaMap__lead`）で区域の外に地名を出しています**。引き出し線は他の市町村を横切らない位置（御代田町の北端から真上）に取っています。他の市町村で同様の対応が必要になった場合は、`<g class="areaMap__lead">` の `<path d="M…">` と `<circle>`、`<text class="areaMap__label areaMap__label--out">` の座標を足してください。

### 出典・ライセンス

> 行政区域：「国土数値情報（行政区域データ）」（国土交通省）を加工して作成

- 元データ：https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N03-v3_1.html
- **公開前に、国土数値情報の利用規約（出典明記の要件）をご確認ください。** 現状はマップ横に上記クレジットを表示しています。

### 作図処理

正距円筒図法（緯度36.20°で経度補正）で投影 → 全体を幅1000のviewBoxに正規化 → Douglas-Peuckerで簡略化（許容誤差1.0）→ SVGパス化。
ラベル位置は各ポリゴンの「内部で最も辺から離れた点」をグリッド探索で算出（小諸市・御代田町のみ重なり回避のため手動で±10調整）。
座標を更新する場合は、各 `<g class="areaMap__region">` 内の `<path d="…">` と `<text>` のx/y座標のみを差し替えれば済みます。

## 8. 画像について

画像はすべて現行サイト（`https://usedrenovation.ooi-kensetsu.co.jp/wp-content/...`）の絶対URLを直接参照しています。移行時は以下のいずれかで対応してください。

1. 同一サーバーへ設置する → 絶対URLを `/wp-content/...` の相対パスへ一括置換
2. 別環境へ設置する → 画像を `assets/img/` へ複製し、参照先を置換

## 9. 実装メモ

- レスポンシブのブレークポイントは `1200px`（ここでドロワーへ切替）／`760px` / `560px`。
- `prefers-reduced-motion` に対応済み。
- 会員ログイン・各フォームは見た目のみのモックです。認証・送信処理は未実装です。
- 会員登録・ログインの導線（ヘッダー／ドロワー／フッター／SP固定CTA／会員限定物件カード）は、すべて `#member` セクションを指しています。ページ下部の `#member-cta`（「Web上の物件は、全体の1割ほどです。」）は訴求用バナーとして併存させています。
